# BMI270 摇动检测示例

## 概述

本示例演示如何使用BMI270传感器的摇动功能来检测摇动手势并触发中断。摇动功能可以识别轻微摇动和重度摇动，并检测不同轴（X、Y、Z）的摇动方向。当检测到摇动时，BMI270通过GPIO中断引脚向ESP32发送信号，ESP32在接收到中断时执行相应的处理逻辑。

## 功能特点

- **摇动检测**: 检测任意方向的摇动手势
- **摇动分类**: 
  - 轻微摇动: 温和摇动检测
  - 重度摇动: 强烈摇动检测
- **轴方向检测**: 识别摇动方向（X、Y、Z轴）
- **GPIO中断**: 使用ESP32 GPIO中断响应摇动检测
- **可配置灵敏度**: 可调整摇动检测灵敏度
- **多平台支持**: 支持多种ESP32开发板
- **实时响应**: 低延迟中断响应机制

## 硬件要求

- ESP32开发板（支持以下型号）:
  - ESP-SPOT-C5
  - ESP-SPOT-S3  
  - ESP-ASTOM-S3
  - ESP-ECHOEAR-S3
  - 自定义开发板
- BMI270传感器模块
- 连接线

## 配置

### 1. Menuconfig配置

运行 `idf.py menuconfig` 进入配置界面：

#### 开发板选择
在 `Component config` -> `BMI270 摇动检测` 中：

- **ESP-SPOT-C5**: 选择此选项使用ESP-SPOT-C5开发板
- **ESP-SPOT-S3**: 选择此选项使用ESP-SPOT-S3开发板
- **ESP-ASTOM-S3**: 选择此选项使用ESP-ASTOM-S3开发板
- **ESP-ECHOEAR-S3**: 选择此选项使用ESP-ECHOEAR-S3开发板
- **自定义开发板**: 选择此选项使用自定义开发板

#### 引脚配置（自定义开发板）
如果选择自定义开发板，需要配置以下引脚：
- **I2C SCL引脚**: I2C时钟引脚
- **I2C SDA引脚**: I2C数据引脚
- **中断引脚**: 中断引脚

### 2. 摇动检测参数配置

您可以在代码中调整以下参数：

```c
// 在set_feature_interrupt函数中修改摇动灵敏度
// 摇动配置由BMI270固件处理
// 如果需要，可以通过修改shake_config数组来调整灵敏度
shake_config[1] = 0x02;  // 降低阈值以提高灵敏度
shake_config[9] = 0x10;  // 降低阈值以提高灵敏度
```

## 引脚连接

### 预定义开发板引脚

#### ESP-SPOT-C5
- 中断引脚: GPIO 3
- I2C SCL: GPIO 26
- I2C SDA: GPIO 25

#### ESP-SPOT-S3
- 中断引脚: GPIO 5
- I2C SCL: GPIO 1
- I2C SDA: GPIO 2

#### ESP-ASTOM-S3
- 中断引脚: GPIO 16
- I2C SCL: GPIO 0
- I2C SDA: GPIO 45

#### ESP-ECHOEAR-S3
- 中断引脚: GPIO 21
- I2C SCL: GPIO 1
- I2C SDA: GPIO 2

### 自定义开发板
通过menuconfig配置自定义引脚，或直接在代码中修改引脚定义。

## 工作原理

### 摇动检测机制

1. **加速度监控**: BMI270持续监控三轴加速度
2. **摇动模式识别**: 分析加速度模式以识别摇动特征
3. **阈值比较**: 当摇动幅度超过设定阈值时触发
4. **轴方向检测**: 确定摇动发生在哪个轴上
5. **中断生成**: 确认摇动后通过INT1引脚发送中断信号

### 摇动识别流程

1. **GPIO配置**: 配置ESP32 GPIO为输入模式，启用中断
2. **中断服务**: 安装GPIO中断服务
3. **中断处理**: 接收到中断时检查摇动状态
4. **摇动分类**: 从寄存器0x1f读取摇动数据并分类摇动

### 检测参数说明

- **摇动灵敏度**: 通过摇动配置寄存器可配置
- **轴方向检测**: X、Y、Z轴摇动检测
- **摇动类型**: 轻微摇动 (0x08) 和重度摇动 (0x80)
- **中断电平**: 高电平有效
- **输出模式**: 推挽输出
- **锁存模式**: 锁存模式

## 使用方法

### 1. 编译和烧录

```bash
cd examples/motion_detection/shake
idf.py set-target esp32s3  # 根据您的开发板选择目标
idf.py menuconfig          # 配置开发板和引脚
idf.py build
idf.py flash monitor
```

### 2. 测试摇动检测

1. 运行程序后，系统将显示当前配置信息
2. 执行摇动手势以触发摇动检测：
   - **轻微摇动**: 任意方向的温和摇动
   - **重度摇动**: 任意方向的强烈摇动
3. 观察串口输出以确认摇动识别和轴方向检测

## 摇动测试方法

### 测试步骤
1. **轻微摇动测试**: 在任意方向温和地摇动设备
2. **重度摇动测试**: 更剧烈地摇动设备
3. **特定轴测试**: 沿特定轴（X、Y、Z）摇动设备
4. **多轴测试**: 在多个方向摇动设备

### 注意事项
- 确保摇动动作自然
- 避免过于剧烈的动作以防止设备损坏
- 测试不同的摇动强度以了解灵敏度
- 等待摇动识别后再执行下一个摇动

## 参数调整

### 提高灵敏度
```c
// 修改摇动配置以提高灵敏度
shake_config[1] = 0x01;  // 降低阈值
shake_config[9] = 0x08;  // 降低阈值
```

### 降低灵敏度
```c
// 修改摇动配置以降低灵敏度
shake_config[1] = 0x04;  // 提高阈值
shake_config[9] = 0x20;  // 提高阈值
```

## 注意事项

- 确保BMI270传感器正确连接到ESP32 I2C引脚
- 中断引脚需要正确连接到BMI270 INT1引脚
- 根据实际应用场景调整摇动灵敏度
- 检测过程中避免过于剧烈的动作
- 摇动检测针对手持设备应用进行了优化

## 故障排除

1. **I2C通信失败**: 检查I2C引脚连接和上拉电阻
2. **中断未触发**: 检查中断引脚连接和配置
3. **摇动识别不准确**: 调整摇动灵敏度参数
4. **编译错误**: 确保选择了正确的硬件平台和引脚配置
5. **无轴方向检测**: 检查摇动数据寄存器读取
