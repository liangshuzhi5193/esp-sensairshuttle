# BMI270 任意动作检测示例（玩具固件）

## 概述

本示例演示如何使用BMI270传感器的任意动作功能配合玩具固件来检测动作并触发中断。当检测到任意动作时，BMI270通过GPIO中断引脚向ESP32发送信号，ESP32在接收到中断时执行相应的处理逻辑。本示例使用玩具固件，提供增强的动作检测功能。

## 功能特点

- **任意动作检测**: 使用玩具固件检测任意方向的动作
- **GPIO中断**: 使用ESP32 GPIO中断响应动作检测
- **玩具固件**: 具有优化算法的增强动作检测
- **可配置阈值**: 可调整动作检测灵敏度
- **多平台支持**: 支持多种ESP32开发板
- **实时响应**: 低延迟中断响应机制
- **简化配置**: 简化的设置过程

## 硬件要求

- ESP32开发板（支持以下型号）:
  - ESP-SPOT-C5
  - ESP-SPOT-S3  
  - ESP-ASTOM-S3
  - ESP-ECHOEAR-S3
  - 自定义开发板
- BMI270传感器模块
- 连接线

## 配置

### 1. Menuconfig配置

运行 `idf.py menuconfig` 进入配置界面：

#### 开发板选择
在 `Component config` -> `BMI270 任意动作检测（玩具固件）` 中：

- **ESP-SPOT-C5**: 选择此选项使用ESP-SPOT-C5开发板
- **ESP-SPOT-S3**: 选择此选项使用ESP-SPOT-S3开发板
- **ESP-ASTOM-S3**: 选择此选项使用ESP-ASTOM-S3开发板
- **ESP-ECHOEAR-S3**: 选择此选项使用ESP-ECHOEAR-S3开发板
- **自定义开发板**: 选择此选项使用自定义开发板

#### 引脚配置（自定义开发板）
如果选择自定义开发板，需要配置以下引脚：
- **I2C SCL引脚**: I2C时钟引脚
- **I2C SDA引脚**: I2C数据引脚
- **中断引脚**: 中断引脚

### 2. 检测参数配置

玩具固件会自动配置任意动作检测的最佳参数。如果需要，您可以在代码中调整以下参数：

```c
// 在set_feature_interrupt函数中修改中断配置
uint8_t data = BMI270_TOY_INT_ANY_MOT_MASK;  // 任意动作中断掩码

// 修改中断引脚配置
pin_config.pin_cfg[0].lvl = BMI2_INT_ACTIVE_HIGH;  // 高电平有效
pin_config.int_latch = BMI2_INT_LATCH;              // 锁存模式
```

## 引脚连接

### 预定义开发板引脚

#### ESP-SPOT-C5
- 中断引脚: GPIO 3
- I2C SCL: GPIO 26
- I2C SDA: GPIO 25

#### ESP-SPOT-S3
- 中断引脚: GPIO 5
- I2C SCL: GPIO 1
- I2C SDA: GPIO 2

#### ESP-ASTOM-S3
- 中断引脚: GPIO 16
- I2C SCL: GPIO 0
- I2C SDA: GPIO 45

#### ESP-ECHOEAR-S3
- 中断引脚: GPIO 21
- I2C SCL: GPIO 1
- I2C SDA: GPIO 2

### 自定义开发板
通过menuconfig配置自定义引脚，或直接在代码中修改引脚定义。

## 工作原理

### 任意动作检测机制（玩具固件）

1. **加速度监控**: BMI270持续监控三轴加速度
2. **高级模式识别**: 玩具固件使用增强算法进行动作检测
3. **阈值比较**: 当加速度变化超过优化阈值时触发
4. **中断生成**: 确认动作后通过INT1引脚发送中断信号

### 中断处理流程

1. **GPIO配置**: 配置ESP32 GPIO为输入模式，启用中断
2. **中断服务**: 安装GPIO中断服务
3. **中断处理**: 接收到中断时检查任意动作状态
4. **状态报告**: 报告动作检测状态

### 检测参数说明

- **中断掩码**: BMI270_TOY_INT_ANY_MOT_MASK (0x40)
- **中断电平**: 高电平有效
- **输出模式**: 推挽输出
- **锁存模式**: 锁存模式
- **固件**: 具有优化检测算法的玩具固件

## 使用方法

### 1. 编译和烧录

```bash
cd examples/motion_detection/any_motion_toy
idf.py set-target esp32s3  # 根据您的开发板选择目标
idf.py menuconfig          # 配置开发板和引脚
idf.py build
idf.py flash monitor
```

```c

// 修改锁存模式

```

## 注意事项

- 中断引脚需要正确连接到BMI270 INT1引脚
- 玩具固件提供增强的动作检测功能
- 检测过程中避免过于剧烈的动作
- 玩具固件针对手持设备应用进行了优化

## 故障排除

1. **I2C通信失败**: 检查I2C引脚连接和上拉电阻
2. **中断未触发**: 检查中断引脚连接和配置
3. **检测不准确**: 玩具固件应该比标准固件提供更好的准确性
4. **编译错误**: 确保选择了正确的硬件平台和引脚配置
5. **固件问题**: 验证玩具固件是否正确加载
