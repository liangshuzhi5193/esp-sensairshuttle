# BMI270 Z 轴翻转检测示例

## 概述

本示例演示了如何使用 BMI270 传感器进行 Z 轴完整翻转检测。通过状态机算法精确跟踪翻转过程，可以检测设备在 Z 轴上的 3 次摇晃动作，适用于设备手势识别等应用场景。

## 功能特点

- **状态机检测**：使用状态机精确跟踪翻转过程
- **实时监控**：持续监控 Z 轴角度变化
- **多平台支持**：支持多种 ESP32 开发板
- **灵活配置**：支持通过 menuconfig 进行引脚配置
- **低功耗设计**：优化的功耗管理

## 硬件要求

- ESP32 开发板（支持以下型号）：
  - ESP-SPOT-C5
  - ESP-SPOT-S3
  - ESP-ASTOM-S3
  - ESP-ECHOEAR-S3
  - 自定义开发板
- BMI270 传感器
- 连接线缆

## 配置说明

### Menuconfig 配置

1. **开发板选择**：
   ```
   Component config -> BMI270 Sensor -> Board Selection
   ```
   选择对应的开发板型号

2. **自定义引脚配置**：
   ```
   Component config -> BMI270 Sensor -> Custom Pin Configuration
   ```
   配置 I2C 引脚：
   - I2C SCL Pin
   - I2C SDA Pin

### 代码配置

在 `main.c` 中可以调整以下参数：

```c
// 检测阈值配置
#define FLIP_THRESHOLD    45.0f  // 翻转阈值 (度)
#define MAX_SAMPLES       100    // 最大采样数
#define DETECTION_DELAY   100    // 检测延时 (ms)
```

## 引脚连接

| ESP32 引脚 | BMI270 引脚 | 说明 |
|------------|-------------|------|
| GPIO 1     | SCL         | I2C 时钟线 |
| GPIO 2     | SDA         | I2C 数据线 |
| 3.3V       | VCC         | 电源正极 |
| GND        | GND         | 电源地 |

## 翻转检测原理

### 状态机流程
1. **初始状态**：等待设备稳定
2. **检测状态**：监控 Z 轴角度变化
3. **翻转状态**：检测到翻转动作
4. **完成状态**：确认翻转完成
5. **重置状态**：准备下一次检测

### 检测算法
- 持续监控 Z 轴角度
- 计算角度变化率
- 判断翻转方向和完整性
- 输出检测结果

## 使用方法

1. **编译和烧录**：
   ```bash
   idf.py build
   idf.py flash monitor
   ```

   - 将设备绕 Z 轴进行翻转
   - 观察串口输出的检测结果
   - 根据实际需求调整检测参数

### 基本测试
1. 将设备平放，正面朝上
2. 绕 Z 轴进行 180° 翻转
3. 观察串口输出的检测结果

### 性能测试
1. 测试不同角度的翻转
2. 测试不同速度的翻转

## 注意事项

- 确保传感器安装稳固，避免振动干扰
- 翻转动作应保持连续性，避免中断
- 根据实际应用调整检测阈值
- 注意环境振动的影响

## 故障排除

### 常见问题
1. **I2C 通信失败**：检查 I2C 引脚连接和上拉电阻
2. **检测不准确**：调整检测阈值或检查翻转动作
3. **响应延迟**：检查系统负载和采样频率
4. **误触发**：调整检测参数或检查环境振动

### 调试建议
- 使用示波器检查 I2C 信号质量
- 检查电源电压稳定性
- 验证传感器配置参数
- 测试不同翻转模式

## 应用场景
