# BMI270 Any-Motion 中断检测示例

## 概述

本示例演示了如何使用 BMI270 传感器进行任意运动中断检测。通过配置运动检测参数和 GPIO 中断，可以从深睡眠中唤醒 ESP32 设备，适用于低功耗应用场景。

## 功能特点

- **任意运动检测**：检测任何方向的运动变化
- **GPIO 中断**：通过 GPIO 中断实时响应运动事件
- **可配置阈值**：支持调整检测阈值和持续时间
- **延时重置**：检测后延时重置，避免重复触发
- **多平台支持**：支持多种 ESP32 开发板
- **实时响应**：低延迟的运动事件响应

## 硬件要求

- ESP32 开发板（支持以下型号）：
  - ESP-SPOT-C5
  - ESP-SPOT-S3
  - ESP-ASTOM-S3
  - ESP-ECHOEAR-S3
  - 自定义开发板
- BMI270 传感器
- 连接线缆

## 配置说明

### Menuconfig 配置

1. **开发板选择**：
   ```
   Component config -> BMI270 Sensor -> Board Selection
   ```
   选择对应的开发板型号

2. **自定义引脚配置**：
   ```
   Component config -> BMI270 Sensor -> Custom Pin Configuration
   ```
   配置 I2C 和中断引脚：
   - I2C SCL Pin
   - I2C SDA Pin
   - Interrupt Pin

### 代码配置

在 `main.c` 中可以调整以下参数：

```c
// 运动检测配置
#define MOTION_THRESHOLD  0xFF  // 运动阈值 (255mg)
#define MOTION_DURATION   0x02  // 持续时间 (40ms)
#define RESET_DELAY       3000  // 重置延时 (ms)
```

## 引脚连接

| ESP32 引脚 | BMI270 引脚 | 说明 |
|------------|-------------|------|
| GPIO 1     | SCL         | I2C 时钟线 |
| GPIO 2     | SDA         | I2C 数据线 |
| GPIO 5     | INT1        | 中断信号线 |
| 3.3V       | VCC         | 电源正极 |
| GND        | GND         | 电源地 |

## 工作原理

### 检测机制
1. **配置运动检测**：设置检测阈值和持续时间
2. **启用中断**：配置 GPIO 中断响应
3. **监控运动**：持续监控加速度变化
4. **触发中断**：检测到运动时触发 GPIO 中断
5. **处理事件**：在中断处理函数中执行相应动作

### 中断流程
1. 传感器检测到运动
2. 触发 INT1 引脚中断
3. ESP32 接收中断信号
4. 执行中断处理函数
5. 延时重置检测

### 参数说明
- **阈值 (Threshold)**：运动检测的敏感度，值越大越不敏感
- **持续时间 (Duration)**：运动必须持续的时间，防止误触发
- **延时重置**：检测后等待时间，避免重复触发

## 参数调整

### 检测阈值调整
- **低阈值 (0x40)**：高敏感度，适合轻微运动
- **中等阈值 (0x80)**：中等敏感度，适合一般应用
- **高阈值 (0xFF)**：低敏感度，适合剧烈运动

### 持续时间调整
- **短时间 (0x01)**：20ms，快速响应
- **中等时间 (0x02)**：40ms，平衡响应和稳定性
- **长时间 (0x03)**：60ms，更稳定的检测

## 注意事项

- 确保传感器安装稳固，避免振动干扰
- 根据实际应用调整检测参数
- 注意环境振动的影响
- 避免在检测期间进行其他剧烈运动

## 故障排除

### 常见问题
1. **I2C 通信失败**：检查 I2C 引脚连接和上拉电阻
2. **中断不触发**：检查中断引脚连接和配置
3. **检测不准确**：调整检测阈值和持续时间
4. **误触发**：调整检测参数或检查环境振动

### 调试建议
- 使用示波器检查 I2C 和中断信号质量
- 检查电源电压稳定性
- 验证传感器配置参数
- 测试不同运动模式
