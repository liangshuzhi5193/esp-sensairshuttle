# BMI270 Circle 手势识别示例

## 概述

本示例演示了如何使用 BMI270 Circle 传感器进行圆形手势识别。通过专用的 circle 固件和优化的算法，可以实现高精度的圆形手势检测，适用于多种应用场景。

## 功能特点

- **多轴检测**：支持 X、Y、Z 三轴加速度和陀螺仪数据
- **可调敏感度**：支持通过代码调整检测敏感度
- **实时处理**：低延迟的手势识别响应
- **多平台支持**：支持多种 ESP32 开发板
- **灵活配置**：支持通过 menuconfig 进行引脚配置

## 硬件要求

- ESP32 开发板（支持以下型号）：
  - ESP-SPOT-C5
  - ESP-SPOT-S3
  - ESP-ASTOM-S3
  - ESP-ECHOEAR-S3
  - 自定义开发板
- BMI270 Circle 传感器
- 连接线缆

## 配置说明

### Menuconfig 配置

1. **开发板选择**：
   ```
   Component config -> BMI270 Sensor -> Board Selection
   ```
   选择对应的开发板型号

2. **自定义引脚配置**：
   ```
   Component config -> BMI270 Sensor -> Custom Pin Configuration
   ```
   配置 I2C 引脚：
   - I2C SCL Pin
   - I2C SDA Pin

### 代码配置

在 `main.c` 中可以调整以下参数：

```c
// XYZ 轴配置
#define X_AXIS_ENABLE    1    // X 轴使能
#define Y_AXIS_ENABLE    1    // Y 轴使能  
#define Z_AXIS_ENABLE    1    // Z 轴使能

// 敏感度配置
#define SENSITIVITY_LEVEL 2    // 敏感度级别 (1-5)
```

## 引脚连接

| ESP32 引脚 | BMI270 引脚 | 说明 |
|------------|-------------|------|
| GPIO 1     | SCL         | I2C 时钟线 |
| GPIO 2     | SDA         | I2C 数据线 |
| 3.3V       | VCC         | 电源正极 |
| GND        | GND         | 电源地 |

## 轴配置说明

### 检测轴选择
- **X 轴**：检测左右方向的圆形手势
- **Y 轴**：检测前后方向的圆形手势  
- **Z 轴**：检测垂直方向的圆形手势

### 敏感度调整
- **级别 1**：最高敏感度，适合精细手势
- **级别 2**：高敏感度，适合一般应用
- **级别 3**：中等敏感度，平衡性能和功耗
- **级别 4**：低敏感度，适合大动作检测
- **级别 5**：最低敏感度，适合粗放手势

## 使用方法

1. **编译和烧录**：
   ```bash
   idf.py build
   idf.py flash monitor
   ```

2. **运行测试**：
   - 在传感器上方进行圆形手势
   - 观察串口输出的检测结果
   - 根据实际需求调整敏感度


## 测试方法

### 基本测试
1. 在传感器上方 5-10cm 处进行圆形手势
2. 保持手势轨迹的连续性
3. 观察串口输出的检测结果

### 性能测试
1. 测试不同大小的圆形手势
2. 测试不同速度的手势
3. 测试不同轴方向的手势

## 注意事项

- 确保传感器安装稳固，避免振动干扰
- 手势轨迹应保持连续性，避免中断
- 根据实际应用调整敏感度参数
- 注意环境光线的干扰

## 故障排除

### 常见问题
1. **I2C 通信失败**：检查 I2C 引脚连接和上拉电阻
2. **检测不准确**：调整敏感度参数或检查手势轨迹
3. **响应延迟**：检查系统负载和中断配置
4. **功耗过高**：调整检测频率和敏感度

### 调试建议
- 使用示波器检查 I2C 信号质量
- 检查电源电压稳定性
- 验证传感器固件版本
- 测试不同手势模式
