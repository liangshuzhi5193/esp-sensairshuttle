# BMI270 空中推压检测示例

## 概述

本示例演示如何使用BMI270传感器的推压功能来检测空中的推压手势并触发中断。推压功能可以识别不同方向（X、Y、Z轴）的推压手势，并提供方向信息。当检测到推压时，BMI270通过GPIO中断引脚向ESP32发送信号，ESP32在接收到中断时执行相应的处理逻辑。

## 功能特点

- **推压检测**: 检测空中的推压手势
- **方向检测**: 识别推压方向（X、Y、Z轴），Z轴精度已改进
- **滚动集成**: 使用滚动数据调整高重力轴选择
- **GPIO中断**: 使用ESP32 GPIO中断响应推压检测
- **可配置灵敏度**: 可调整推压检测灵敏度，优化阈值设置
- **多平台支持**: 支持多种ESP32开发板
- **实时响应**: 低延迟中断响应机制
- **Z轴方向修复**: 使用原始加速度数据增强Z轴方向检测

## 硬件要求

- ESP32开发板（支持以下型号）:
  - ESP-SPOT-C5

## 工作原理

### 推压检测机制

1. **加速度和陀螺仪监控**: BMI270持续监控三轴加速度和陀螺仪
2. **推压模式识别**: 分析加速度模式以识别推压特征
3. **方向检测**: 确定推压发生在哪个轴上
4. **滚动集成**: 使用滚动数据动态调整高重力轴选择
5. **中断生成**: 确认推压后通过INT1引脚发送中断信号

### 推压识别流程

1. **GPIO配置**: 配置ESP32 GPIO为输入模式，启用中断
2. **中断服务**: 安装GPIO中断服务
3. **中断处理**: 接收到中断时检查推压状态
4. **方向分析**: 使用高重力方向函数读取推压方向
5. **轴调整**: 基于滚动数据调整高重力轴选择

### 检测参数说明

- **高重力阈值**: 0x0800 - 推压检测灵敏度
- **推压中断掩码**: BMI270_TOY_INT_PUSH_MASK (0x20)
- **滚动中断掩码**: BMI270_TOY_INT_GI_INS1_ROLLING_MASK (0x10)
- **中断电平**: 高电平有效
- **输出模式**: 推挽输出
- **锁存模式**: 锁存模式

## Z轴方向检测修复

### 问题描述
原始的`get_toy_high_g_direction`函数在Z轴方向检测方面存在缺陷。寄存器0x38的bit3（符号位）在Z轴检测时总是被设置为1，导致所有Z轴推压都被报告为"+Z"，无论实际方向如何。

### 解决方案实现
该函数已增强以正确检测Z轴方向：

1. **X和Y轴**: 继续使用标准符号位（bit3）进行方向检测
2. **Z轴**: 使用寄存器0x12的原始加速度数据确定方向：
   - 读取6字节加速度数据（X、Y、Z轴）
   - 提取Z轴加速度值
   - 根据Z轴加速度符号确定方向：
     - `accel_z > 0`: "+Z"（向上推压）
     - `accel_z < 0`: "-Z"（向下推压）

### 代码变更
```c
// 在get_toy_high_g_direction()中增强的Z轴方向检测
else if (high_g_out[0] & 0x04) {
    direction[1] = 'z';
    // Z轴需要特殊处理：通过读取原始加速度数据来判断方向
    uint8_t accel_data[6];
    rslt = bmi2_get_regs(0x12, accel_data, 6, bmi2_dev);
    if (rslt == BMI2_OK) {
        int16_t accel_z = (int16_t)(accel_data[5] << 8) | accel_data[4];
        
        // 根据Z轴加速度的符号判断方向
        if (accel_z > 0) {
            direction[0] = '+';  // 向上推压
        } else {
            direction[0] = '-';  // 向下推压
        }
    }
}
```

### 优势
- **准确的Z轴方向**: 现在可以正确区分向上和向下推压
- **向后兼容性**: X和Y轴检测保持不变
- **健壮的错误处理**: 如果加速度计读取失败，回退到原始方法
- **改进的用户体验**: Z轴运动的手势识别更准确

## 故障排除

1. **I2C通信失败**: 检查I2C引脚连接和上拉电阻
2. **中断未触发**: 检查中断引脚连接和配置
3. **推压识别不准确**: 调整高重力阈值参数
4. **编译错误**: 确保选择了正确的硬件平台和引脚配置
5. **无方向检测**: 检查高重力方向函数
6. **Z轴方向问题**: 验证加速度计数据读取和方向逻辑
