# BMI270 玩具动作手势识别示例

## 概述

本示例演示如何使用BMI270传感器的玩具动作功能来检测各种玩具手势并触发中断。玩具动作功能可以识别五种不同的手势：拿起、放下、向上抛、向下抛和抛接。当检测到手势时，BMI270通过GPIO中断引脚向ESP32发送信号，ESP32在接收到中断时执行相应的处理逻辑。

## 功能特点

- **玩具动作检测**: 检测五种不同的玩具手势
- **手势识别**: 
  - 拿起 (0x01): 设备被拿起
  - 放下 (0x02): 设备被放下
  - 向上抛 (0x03): 设备被向上抛出
  - 向下抛 (0x04): 设备被向下抛出
  - 抛接 (0x05): 设备被抛出并接住
- **GPIO中断**: 使用ESP32 GPIO中断响应手势检测
- **可配置参数**: 可调整手势检测灵敏度
- **多平台支持**: 支持多种ESP32开发板
- **实时响应**: 低延迟中断响应机制

## 硬件要求

- ESP32开发板（支持以下型号）:
  - ESP-SPOT-C5
  - ESP-SPOT-S3  
  - ESP-ASTOM-S3
  - ESP-ECHOEAR-S3
  - 自定义开发板
- BMI270传感器模块
- 连接线

## 配置

### 1. Menuconfig配置

运行 `idf.py menuconfig` 进入配置界面：

#### 开发板选择
在 `Component config` -> `BMI270 玩具动作手势识别` 中：

- **ESP-SPOT-C5**: 选择此选项使用ESP-SPOT-C5开发板
- **ESP-SPOT-S3**: 选择此选项使用ESP-SPOT-S3开发板
- **ESP-ASTOM-S3**: 选择此选项使用ESP-ASTOM-S3开发板
- **ESP-ECHOEAR-S3**: 选择此选项使用ESP-ECHOEAR-S3开发板
- **自定义开发板**: 选择此选项使用自定义开发板

#### 引脚配置（自定义开发板）
如果选择自定义开发板，需要配置以下引脚：
- **I2C SCL引脚**: I2C时钟引脚
- **I2C SDA引脚**: I2C数据引脚
- **中断引脚**: 中断引脚

### 2. 手势检测参数配置

您可以在代码中调整以下参数：

```c
// 在adjust_toy_motion_config函数中修改检测参数
uint16_t throw_min_duration = 0x06;    // 增加最小持续时间以减少误触发
uint16_t throw_up_duration = 0x03;     // 增加向上抛持续时间以改善向上抛识别
uint16_t low_g_exit_duration = 0x02;   // 增加低重力退出持续时间以改善向下抛识别
uint16_t quiet_time_duration = 0x04;   // 增加静默时间持续时间以改善抛接识别
uint16_t slope_thres = 0x1000;         // 增加斜率阈值以减少向下抛被误识别为碰撞
```

## 引脚连接

### 预定义开发板引脚

#### ESP-SPOT-C5
- 中断引脚: GPIO 3
- I2C SCL: GPIO 26
- I2C SDA: GPIO 25

#### ESP-SPOT-S3
- 中断引脚: GPIO 5
- I2C SCL: GPIO 1
- I2C SDA: GPIO 2

#### ESP-ASTOM-S3
- 中断引脚: GPIO 16
- I2C SCL: GPIO 0
- I2C SDA: GPIO 45

#### ESP-ECHOEAR-S3
- 中断引脚: GPIO 21
- I2C SCL: GPIO 1
- I2C SDA: GPIO 2

### 自定义开发板
通过menuconfig配置自定义引脚，或直接在代码中修改引脚定义。

## 工作原理

### 玩具动作检测机制

1. **加速度和陀螺仪监控**: BMI270持续监控三轴加速度和陀螺仪
2. **手势模式识别**: 分析运动模式以识别特定手势
3. **阈值比较**: 当运动特征匹配手势模式时触发
4. **中断生成**: 确认手势后通过INT1引脚发送中断信号

### 手势识别流程

1. **GPIO配置**: 配置ESP32 GPIO为输入模式，启用中断
2. **中断服务**: 安装GPIO中断服务
3. **中断处理**: 接收到中断时检查玩具动作状态
4. **手势分类**: 从寄存器0x1e读取手势类型并分类手势

### 检测参数说明

- **抛出最小持续时间**: 0x06 - 抛出手势的最小持续时间
- **向上抛持续时间**: 0x03 - 向上抛识别持续时间
- **低重力退出持续时间**: 0x02 - 低重力退出持续时间（向下抛）
- **静默时间持续时间**: 0x04 - 静默期持续时间（抛接）
- **斜率阈值**: 0x1000 - 碰撞检测阈值

## 使用方法

### 1. 编译和烧录

```bash
cd examples/gesture_recognition/toy_motion
idf.py set-target esp32s3  # 根据您的开发板选择目标
idf.py menuconfig          # 配置开发板和引脚
idf.py build
idf.py flash monitor
```

### 2. 测试手势检测

1. 运行程序后，系统将显示当前配置信息
2. 执行不同手势以触发玩具动作检测：
   - **拿起**: 拿起设备
   - **放下**: 放下设备
   - **向上抛**: 向上抛出设备
   - **向下抛**: 向下抛出设备
   - **抛接**: 抛出设备并接住
3. 观察串口输出以确认手势识别

## 手势测试方法

### 测试步骤
1. **拿起测试**: 从表面轻轻拿起设备
2. **放下测试**: 轻轻将设备放在表面上
3. **向上抛测试**: 快速向上抛出设备并让其落下
4. **向下抛测试**: 快速向下抛出设备
5. **抛接测试**: 向上抛出设备并平稳接住

### 注意事项
- 确保手势动作自然流畅
- 避免过于剧烈的动作以防止设备损坏
- 对于抛出手势，确保有足够的空间进行安全测试
- 等待手势识别后再执行下一个手势

## 参数调整

### 提高灵敏度
```c
uint16_t throw_min_duration = 0x04;    // 减少最小持续时间
uint16_t throw_up_duration = 0x02;     // 减少向上抛持续时间
uint16_t low_g_exit_duration = 0x01;   // 减少低重力退出持续时间
uint16_t quiet_time_duration = 0x02;   // 减少静默时间持续时间
```

### 降低灵敏度
```c
uint16_t throw_min_duration = 0x08;    // 增加最小持续时间
uint16_t throw_up_duration = 0x04;     // 增加向上抛持续时间
uint16_t low_g_exit_duration = 0x03;   // 增加低重力退出持续时间
uint16_t quiet_time_duration = 0x06;   // 增加静默时间持续时间
```

## 注意事项

- 确保BMI270传感器正确连接到ESP32 I2C引脚
- 中断引脚需要正确连接到BMI270 INT1引脚
- 根据实际应用场景调整检测参数
- 检测过程中避免过于剧烈的动作
- 对于抛出手势，确保有足够的空间和安全措施

## 故障排除

1. **I2C通信失败**: 检查I2C引脚连接和上拉电阻
2. **中断未触发**: 检查中断引脚连接和配置
3. **手势识别不准确**: 调整手势检测参数
4. **编译错误**: 确保选择了正确的硬件平台和引脚配置
5. **手势检测混合**: 微调持续时间和阈值参数
